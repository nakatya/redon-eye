## 目的
世界をほぼ真っ暗にし、目の周囲だけが柔らかく見える「視界」を実装する。

## やること
- 画面全体を闇で覆い、目を中心に半径 160px の円だけが見えるようにする
- 円の縁はハードに切らず、外側へ向かってなだらかに暗くなる(グラデーション)
- 視界の半径は後で変えられるよう、Eye(またはシーン)のプロパティにする
- 確認用に、ステージ上にグレーの目印をいくつか置く(後の Issue で置き換えてよい)

## 受け入れ条件
- [ ] 目の周囲だけが見え、縁がぼやけている
- [ ] 目を動かすと視界も追従し、目印が闇から現れたり消えたりする
- [ ] 60fps 程度で動く(重い処理を毎フレーム作り直していない)
