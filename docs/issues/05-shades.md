## 目的
影の生き物(Shade)を実装し、触れると体力が減るようにする。

## やること
- `src/entities/Shade.ts`: 輪郭のぼやけた黒い不定形。ゆらゆら揺れる
- 4体をステージに配置。ふだんはゆっくり徘徊し、目の視界に入ると少し近寄る(目より遅い)
- 体力 3。触れると 1 減り、2 秒間無敵(目が点滅)
- 右上に体力を小さな目のアイコンで表示
- 体力 0 でゲームオーバー → 結果画面へ
- 当たり判定・無敵時間・体力計算は `src/logic/` に置きテストする

## 受け入れ条件
- [ ] 影は闇の中では見えず、視界に入ると現れて寄ってくる
- [ ] 触れると体力が減り、無敵中は重ねてダメージを受けない
- [ ] 体力0でゲームオーバーになる
- [ ] ロジックのテストがある
