## 目的
画面全体に、ルドンの木炭画・リトグラフを思わせる質感をかける。

## やること
- `src/shaders/` に WebGL のポストエフェクト(Phaser の PostFX Pipeline)を作る
- 効果: 紙の粒子ノイズ(時間で少し揺らぐ)、周辺減光(ビネット)、わずかなにじみ、低コントラストのグレー階調への変換
- 強さはパラメータで調整できるようにする
- WebGL が使えない環境ではエフェクトなしで動く

## 受け入れ条件
- [ ] ゲーム画面全体が木炭で描いたような質感になる
- [ ] フレームレートが大きく落ちない
- [ ] PR に before / after のスクリーンショットを貼る
