# ゲームデザイン(v0.1)

仮タイトル: **「眼は漂う」(The Eye Drifts)**

## コンセプト
闇の中に、ひとつの目が浮かんでいる。
目が見ている範囲だけが世界として現れ、それ以外は黒に沈む。
静かで、少し不安で、夢の中のような 1〜3 分の探索体験。

## コアループ
1. 目を操作して闇の中を漂う
2. 周囲の淡い光で、近くのものだけが見える
3. 光の粒(Mote)を集める
4. 影の生き物(Shade)に触れないように避ける
5. 規定数の粒を集めると出口が現れ、たどり着くとクリア

## 操作
- PC: 矢印キー / WASD で移動
- スマホ(後回しで可): 画面ドラッグで移動
- 移動は慣性があり、ゆっくり漂うような手触りにする(急停止しない)

## ルール
| 項目 | 初期値(調整前提) |
|---|---|
| 画面サイズ | 960 × 540(拡大縮小対応) |
| ステージの広さ | 画面の約 3 × 3 倍。カメラはプレイヤーを追従 |
| 視界の半径 | 160px。粒を集めるたびに少しずつ広がる |
| 光の粒 | ステージ上に 12 個、クリア条件は 8 個 |
| 影の生き物 | 4 体。ゆっくり徘徊し、視界に入ると少し近寄ってくる |
| 体力 | 3。影に触れると 1 減り、2 秒間無敵 |
| 時間 | 制限なし(経過時間を記録として表示) |

## 画面
- タイトル: 黒い画面にタイトル文字と「クリックで始める」
- ゲーム中: 左上に集めた粒の数、右上に体力(小さな目のアイコン)
- ゲームオーバー / クリア: 結果(粒の数・経過時間)と「もう一度」

## 見た目と音
- モノクロ。数段階のグレーで描く
- 画面全体に紙の粒子ノイズと周辺減光
- 目は白目と黒い瞳で、移動方向を見るように瞳が動く
- 影の生き物は輪郭のぼやけた黒い形で、ゆらゆら揺れる
- 音(後回しで可): 低いドローン音、粒を取ったときの小さな鐘の音
